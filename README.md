EMBERLIGHT — Last Lantern is a complete 2D arena-survival game: you are the last lantern keeper, surviving 10 waves of zombies across 4 rooms joined by doorways, lighting 4 braziers, with auto-aim, a Lantern Nova ultimate and 10 temporary hidden skills including Ghost Veil invisibility. Pure vanilla HTML/Canvas JavaScript — no libraries, no build step, no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
